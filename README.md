# XolosaX

![XolosaX](brand/png/xolosax-banner.png)

**A premium personal brand at the intersection of music, technology, and entrepreneurship.**

This repository holds the complete **XolosaX visual identity** — an ownable symbol (the
*Woven X* resonance mark), a custom geometric wordmark, lockups, an app icon, a favicon,
a disciplined matte-black / white / saxophone-gold palette, and a full brand showcase.

All artwork is **vector SVG**, so it scales flawlessly from a favicon to a brushed-metal
plaque and works in monochrome, gold foil, embossing, and engraving.

→ **[Brand guidelines & full asset index: `brand/README.md`](brand/README.md)**
→ **Identity presentation & mockups: [`brand/showcase.html`](brand/showcase.html)**
→ **Inquiry → booking funnel (form, pipeline tracker, templates): [`funnel/README.md`](funnel/README.md)**
