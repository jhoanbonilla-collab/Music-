# Bella — Sitio web con tienda digital

Sitio web de una sola página para **Bella**, boutique de belleza y cuidado personal.

![Logo Bella](assets/bella-logo.svg)

## Contenido

```
bella/
├── index.html                  página completa (HTML + CSS + JS, sin dependencias)
└── assets/
    ├── bella-monogram.svg      monograma "B" con pétalo (favicon / app icon)
    └── bella-logo.svg          lockup horizontal: monograma + wordmark
```

## Características

- **Logo llamativo**: monograma "B" con bowls en forma de pétalo, degradado
  rosa–coral–dorado sobre berenjena profundo. Todo en SVG vectorial.
- **Tienda digital**: catálogo de 6 productos, carrito lateral con cantidades,
  total en vivo, persistencia en `localStorage` y checkout de demostración
  (no procesa pagos reales).
- **Secciones**: hero, tienda, nosotros y contacto. Diseño responsivo, en español.

## Cómo verla

Abre `bella/index.html` en cualquier navegador — no requiere servidor ni build.
